# Returns and Exchanges

## Standard return window
Unused products in original packaging may be returned within 30 days of delivery for a refund to the original payment method. The customer pays return shipping unless Acme shipped the wrong item or the item arrived damaged.

## Final sale and exceptions
Items marked Final Sale, gift cards, and personalized products cannot be returned. If an order arrived damaged, customers must report it within 7 days and include photos; Acme provides a prepaid label after confirming the damage.

## Exchanges
Size exchanges are available within 30 days for unused apparel, subject to stock. One exchange shipment per order is free; a second exchange requires the customer to pay shipping.
